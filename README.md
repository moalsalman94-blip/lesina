# LESINA Cosmetics — المتجر الإلكتروني

متجر إلكتروني بسيط وسريع (HTML / CSS / JavaScript بدون أي build) لبيع **بكج ليسينا الكامل**:
شاور جل + سكرب + بودي سبلاش + زبدة الجسم بسعر **25 دينار**.

## المميزات
- تصميم فاخر بالعربي (RTL) ومتجاوب مع الموبايل
- سلة تسوق جانبية (إضافة، تعديل الكمية، حذف) محفوظة في المتصفح
- نموذج إتمام طلب (الاسم، الهاتف، المدينة، العنوان) مع الدفع عند الاستلام
- إرسال الطلب على واتساب (اختياري)

## التشغيل
افتحي `index.html` مباشرة بالمتصفح، أو:

```bash
python3 -m http.server 8000
```

## التعديل
كل الإعدادات في أعلى ملف `app.js`:
- `CONFIG.whatsappNumber` — رقم واتساب لاستقبال الطلبات (مثال `962791234567`)
- `CONFIG.deliveryFee` — رسوم التوصيل (`null` = تُحدَّد عند التأكيد، `0` = مجاني)
- `BUNDLE_ITEMS` / `PRODUCTS` — أسماء المنتجات والأوصاف والأسعار والصور

## الصور
الصور الحالية في مجلد `images/` رسومات مؤقتة. لاستبدالها بصور حقيقية ضعي الصور في نفس المجلد
وعدّلي مسار `image` في `app.js` (وفي قسم الـ hero داخل `index.html`).

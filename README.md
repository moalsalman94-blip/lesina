# Revira Hair Care — المتجر الإلكتروني

متجر إلكتروني بالإنجليزي (HTML / CSS / JavaScript بدون أي build) لمنتجات **Revira Hair Care**:

| المنتج | الحجم | السعر |
|---|---|---|
| Shampoo | 500 ml | 15 JD |
| Conditioner | 500 ml | 12 JD |
| Hair Mask | 250 ml | 10 JD |
| Hair Oil | 250 ml | 20 JD |

## المميزات
- تصميم فاخر متجاوب مع الموبايل، بصور المنتجات الحقيقية
- صفحة تفاصيل لكل منتج (الفوائد، المكونات، صورة المكونات)
- بكج الروتين الكامل (الأربع منتجات) بـ 45 JD بدل 57 — السعر في `SET` بأعلى `app.js`
- حقيبة تسوق محفوظة في المتصفح، ونموذج طلب، وإرسال الطلب على واتساب

## الملفات
- `index.html` — هيكل الصفحة
- `styles.css` — التصميم
- `app.js` — المنتجات والأسعار والحقيبة وإتمام الطلب
- `fx.js` — الحركة: شاشة البداية، التمرير الناعم، حركات الأقسام، المؤشر
- `img/` — صور المنتجات (`shampoo.webp` …) وصور المكونات (`sheet-*.webp`) وصور الحملة (`lineup-*.webp`)

لو ما اشتغلت مكتبات الحركة عند حدا، المتجر بيضل شغال عادي.

## التشغيل
افتحي `index.html` مباشرة بالمتصفح، أو:

```bash
python3 -m http.server 8000
```

## التعديل
كل الإعدادات في أعلى ملف `app.js`:
- `CONFIG.whatsappNumber` — رقم واتساب لاستقبال الطلبات
- `CONFIG.deliveryFee` — رسوم التوصيل (`null` = تُحدَّد على واتساب، `0` = مجاني)
- `PRODUCTS` — الأسماء والأحجام والأسعار والأوصاف والمكونات والصور
- `INGREDIENTS` — قسم المكونات

## بعد أي تعديل على `styles.css` أو `app.js` أو الصور
زيدي رقم النسخة بآخر الروابط داخل `index.html` (مثال `styles.css?v=10` ← `styles.css?v=11`)،
وزيدي `ASSET_VERSION` بأعلى `app.js` لما تتغير الصور،
عشان المتصفحات ما تضل تستعمل النسخة القديمة المحفوظة عندها.

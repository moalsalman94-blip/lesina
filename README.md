# LESINA Cosmetics — المتجر الإلكتروني

متجر إلكتروني بسيط وسريع (HTML / CSS / JavaScript بدون أي build) لبيع **بكج ليسينا الكامل**:
شاور جل + سكرب + بودي سبلاش + زبدة الجسم بسعر **25 دينار**.

## المميزات
- تصميم فاخر بالعربي (RTL) ومتجاوب مع الموبايل
- سلة تسوق جانبية (إضافة، تعديل الكمية، حذف) محفوظة في المتصفح
- نموذج إتمام طلب (الاسم، الهاتف، المدينة، العنوان) مع الدفع عند الاستلام
- اختيار الريحة (Aster / Lily / Camellia) والصور بتتغير حسبها
- إرسال تفاصيل الطلب على واتساب ليسينا

## التشغيل
افتحي `index.html` مباشرة بالمتصفح، أو:

```bash
python3 -m http.server 8000
```

## التعديل
كل الإعدادات في أعلى ملف `app.js`:
- `CONFIG.whatsappNumber` — رقم واتساب لاستقبال الطلبات (حالياً `962790335444`)
- `CONFIG.deliveryFee` — رسوم التوصيل (`null` = تُحدَّد عند التأكيد، `0` = مجاني)
- `SCENTS` — الروايح المتوفرة
- `BUNDLE_ITEMS` / `PRODUCTS` — أسماء المنتجات والأوصاف والأسعار

## الصور
الصور الحالية في مجلد `images/` رسومات مؤقتة، صورة لكل منتج بكل ريحة باسم `<المنتج>-<الريحة>.svg`
(مثال `body-butter-aster.svg`). لاستبدالها بصور حقيقية ضعيها بنفس الأسماء، ولو كانت `.jpg` عدّلي الامتداد في `imageFor` داخل `app.js`.
